# Hosts the LicketySync binaries may contact: one bare hostname or IPv4 address
# per line, lowercase, nothing else on the line.
# ci/no-hostnames.sh (run by gate.sh and CI) fails when a hostname inside a string
# literal under crates/ is not listed here. Add a host only in the change that adds
# the feature which contacts it, and only for a feature that is off until the user
# turns it on (plan: "The binary contacts no host the user did not turn on").
# Listing a host does not cover its subdomains. Of the project's own domains the
# check exempts only the join-link prefix: it removes the exact text
# https://licketysync.app/join# and checks the rest of the string, so a URL that
# begins with it passes, and the reviewers confirm that the binaries, which parse
# and write join links, never request it. Any other host on those domains is
# listed here like any other. Loopback, unspecified and the documentation address
# ranges are exempt; any other address code names is listed here with a note on
# when it is used (LAN discovery's mDNS group, 224.0.0.251, comes with the mDNS
# carrier). An address computed at run time, such as an interface's directed
# broadcast address, is in no string, and IPv6 addresses, ff02::fb among them, are
# not checked: threat-model.md TM-31 notes them. The check catches accidents, not
# adversaries: lowercase names under six top-level domains, in one-line string
# literals in .rs files; the reviewers cover the rest.
#
# The binaries contact nothing yet, so this list is empty.
